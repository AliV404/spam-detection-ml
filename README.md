# 📧 Spam Detection - Machine Learning Assignment

## Overview
Binary text classification model that detects whether an SMS message is spam or not, 
built using Naive Bayes algorithm and TF-IDF feature engineering.

## Dataset
- **Name:** Spam Text Message Classification
- **Source:** [Kaggle](https://www.kaggle.com/datasets/team-ai/spam-text-message-classification)
- **Size:** 5,572 SMS messages
- **Labels:** spam / ham (not spam)

## Tech Stack
- Python
- Jupyter Notebook
- scikit-learn (TF-IDF)
- pandas, numpy

## Project Structure
- `spam_detection.ipynb` — main notebook with full implementation
- `spam.csv` — dataset file

## How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas numpy scikit-learn`
3. Open `spam_detection.ipynb` in Jupyter
4. Run all cells top to bottom

- ✅ Part 2 - Feature Engineering (TF-IDF)

- ✅ Part 4 - Model Training
- ✅ Part 5 - Testing & Evaluation
